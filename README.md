# Bookstore API

A backend application built with Spring Boot for managing books and library operations through RESTful APIs.

## Features
- RESTful APIs
- CRUD Operations
- Pagination & Sorting
- Search Functionality
- Exception Handling
- DTO Architecture
- Logging
- Layered Architecture
- Spring Data JPA Integration

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok

## Tools
- Postman
- Git & GitHub
- Docker (Basic Knowledge)

## Project Architecture
The project follows a layered architecture structure:
- Controller Layer
- Service Layer
- Repository Layer
- DTO Layer

## Future Improvements
- Spring Security & JWT Authentication
- Unit Testing
- Docker Containerization
- Role-Based Authorization
